# M5-1 探查：本人授权（E1、E2，给用户执行）

> 适合谁读：在这台 Mac 上执行探查的人（项目的用户本人）。
> 结论文档在 `docs/m5-probe.md`；这份脚本回答其中“等用户的结果”的两项。

## 这份脚本会做什么

- **会弹出两次系统的授权框**（和装软件时要密码的那种框一样）。第一次请用你的**登录密码或指纹**授权；第二次如果出现，请点**取消**。
- **终端里会要一次管理员密码**（`sudo`）：用来在系统的授权数据库里登记、最后删除一个权限项。
- **改了系统的什么**：只在授权数据库里**登记一条**我们自己的权限项 `com.claude-abroad.sensitive`，脚本结束时（正常结束、出错、Ctrl+C 都会）**删除它**。不碰授权数据库里别的规则，不改网络，不改任何设置。
- 不需要断网，不影响 Claude Code 会话，约 3 分钟。

## 执行

在仓库根目录，用你自己的账号（**不要** `sudo` 整个脚本）：

```sh
scripts/m5/probe/run-e1e2.sh
```

过程中会问你三个问题，照实回答：

1. 第一个授权框上显示的**申请者名字**（照原样输入；看不清就写“看不清”）；
2. 提示文字是不是“Claude 出国要执行一项敏感操作（M5-1 探查用…）”；
3. 第二个程序申请时**是否又弹出了授权框**。

## 它在验证什么

| 步骤 | 验证 |
|---|---|
| 登记、读规则 | 未签名（ad-hoc 签名）的程序能否登记自定义权限项；规则是否是“本人认证、不共享、不缓存” |
| 第一次申请 | 未签名的程序能否申请到它；授权框显示的申请者名字和提示文字 |
| 以 root 核验（Swift、Go 各一次） | abroadd（以 root 运行）能否不带交互地核验应用交来的授权；Go 一侧用一个只链接系统框架的极小 cgo 文件 |
| 核验没登记的权限项 | 应不通过（对照） |
| 第二个进程申请 | 规则不共享时，别的进程用自己的授权会话申请同一个权限项，**应再次弹框**（不能沾第一次授权的光） |
| 会话结束后再核验 | 应用退出（授权会话结束）后，它交出的授权是否随之失效（记录） |
| 删除、再读 | 权限项已删除 |

## 出问题怎么办

- 中途卡住：按 Ctrl+C，脚本会删除登记的权限项。
- 脚本提示“删除权限项失败”：手动执行 `sudo scripts/m5/probe/swift/.build/debug/AuthzProbe remove`，再执行 `scripts/m5/probe/swift/.build/debug/AuthzProbe show` 确认读不到。

## 贴回什么

`scripts/m5/probe/out/e1e2-<时间>.txt` 的全部内容（你的用户名已经换成 `<用户>`）。
