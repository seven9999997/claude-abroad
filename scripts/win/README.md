# Windows 断网规则探查（WR1 第一级）

> 适合谁读：在自己的 Windows 10/11（x64）电脑上执行探查的人。
> 这是 WR1 三级探查里的**第一级**（design-windows 0.3、0.5）。第二级（持久过滤器）、第三级（开机过滤器、重启）以后另给说明，要求你人在电脑旁边。

## 应急步骤（先读这一节）

第一级只用 **动态过滤器**：探查程序一退出，Windows 自动删除它装的全部规则，**不会留下残留**，重启也不需要。

如果探查期间或之后上不了网：

1. **结束探查程序**：在运行它的窗口按 `Ctrl+C`，或者在任务管理器里结束 `abroad-wfp-probe.exe`。规则随之消失，网络恢复。
2. 仍然不行：以管理员身份打开 PowerShell，进入程序所在目录，执行
   ```powershell
   .\abroad-wfp-clean.exe            # 先空跑，看有没有 Claude 出国的对象
   .\abroad-wfp-clean.exe --delete   # 真的删除，删完会再检查一遍
   ```
3. 还原工具也不行：重启电脑（动态过滤器不会跨过重启）。

最坏的情况是外网中断 **120 秒**（或者你用 `--seconds` 设的时长，最长 300 秒），到点程序自动退出。期间局域网照常（打印机、NAS、路由器后台、同一网络里的其他电脑）。

## 准备

- 一台 x64 的 Windows 10 或 11，**管理员权限**（在“以管理员身份运行”的 PowerShell 里执行）。
- 两个程序放在同一个目录（例如 `C:\abroad-dev\`）：`abroad-wfp-probe.exe`、`abroad-wfp-clean.exe`。
- （可选，验证“按账户放行”）这台电脑上另一个**普通**本地账户（不是 Administrator）。没有的话这一项会记“未执行”，不影响其他项。查它的 SID：
  ```powershell
  (New-Object System.Security.Principal.NTAccount("另一个账户名")).Translate([System.Security.Principal.SecurityIdentifier]).Value
  ```
- 预计时长：约 3 分钟，其中外网中断约 1 分钟（各项做完就结束，不等满时限）。

## 执行

```powershell
cd C:\abroad-dev
.\abroad-wfp-clean.exe                                  # 1. 还原工具空跑：应显示“没有找到…不需要还原”
.\abroad-wfp-probe.exe                                  # 2. 只打印计划和预测，不装任何规则
.\abroad-wfp-probe.exe --yes                            # 3. 正式探查（外网中断，最长 120 秒）
# 或者带上另一个账户：
.\abroad-wfp-probe.exe --yes --allow-sid S-1-5-21-…-1002
```

带 `--allow-sid` 时，程序装好规则后会提示一条命令。**在 60 秒内**另开一个窗口，用另一个账户执行它（会要求输入那个账户的密码）：

```powershell
runas /user:另一个账户名 "C:\abroad-dev\abroad-wfp-probe.exe --child C:\abroad-dev\child-result.txt"
```

## 贴回什么

把 `C:\abroad-dev\probe-result.txt` 的全部内容贴回来。文件里的机器名、账户名已经换成 `<本机名>`，私有地址只保留前两段，SID 只保留最后的编号。

结果里每一项有“预测 / 实际 / 判定”。标着 `←←← 不一致` 的项最重要；文件末尾有探查前后别家软件（代理、VPN、安全软件）在出站连接层的过滤器名字和数量，用来判断不一致是不是被它们影响。结果不干净时，可能请你临时关掉代理软件和 VPN 再跑一次作对照。

## 由开发者远程执行时的规程（design-windows 0.2）

- **只有第一级可以远程执行**；第二、三级必须你人在电脑旁边。
- 条件：规则保持“允许局域网”，开发机的 SSH 连接在放行范围内；开始前用离线求值器预测“从开发机到这台电脑 SSH 端口的回包”必须放行（程序带 `--keep-host <开发机地址>` 时自动检查，不满足就拒绝开始）；探查以后台方式启动，结果写文件，自带时限；开始前先远程跑一次还原工具的空跑；**开始前在对话里告诉你“接下来两分钟那台电脑会断外网”，得到你的答复再做**。
- 不在这台电脑上留下多余的东西：程序只放在 `C:\abroad-dev\`，结束后删除；不改系统设置；不动代理软件和 VPN。

## 程序做了什么

- 在 WFP 里建一个提供者 “Claude Abroad” 和它的子层，在出站连接层（ALE_AUTH_CONNECT_V4/V6）装一组动态过滤器：回环放行；指定账户的 TCP/UDP 放行；DHCP 到广播和私有地址放行；本机直连的局域网段、链路本地、组播放行；其余 IPv4 拦截；IPv6 除回环外一律拦截。
- 逐项尝试：回环、公网 TCP（1.1.1.1:443）、公网 DNS（1.1.1.1:53）、默认网关 TCP 80、公网 IPv6、装规则之前建立的连接、另一个账户的连接、枚举到的规则是否与期望一致。
- 退出时规则随会话关闭被系统删除，程序再枚举一次确认没有残留。
- 不读配置文件，不安装服务，不改防火墙设置和网卡设置，不碰别家软件的任何规则。
