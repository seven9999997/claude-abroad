# scripts/m6/resolver：解析锁的真机验证（M6-3，R9、R18）

> **先读这两条风险（两个方向）**
>
> 1. **锁有效时**：本机的 Claude（桌面版、Claude Code，可能包括正在运行的会话）可能连不上，直到脚本删掉锁文件。
> 2. **锁无效时**：这个实验本来就可能得出“锁无效”的结论，而运行期间本机**没有任何网络接管**。这时你按提示打开的已登录 Claude（Claude Code、桌面版、浏览器里已登录的页面）**会真的连上 Anthropic**。如果这台 Mac 能直连 Anthropic，**已登录的账号就会从本机 IP 访问**——这正是本项目要避免的事。
>
> 所以脚本在基线阶段先用两条不带凭据的 `curl` 判断“不经任何代理能不能到 Anthropic”，结果分三种：**到不了**、**能到（经本机的代理或 TUN）**、**能到（直连）**；判断不了时按直连处理。除了“到不了”，已登录程序的观察都**默认跳过**，只做不带凭据的几项（系统解析器、dig、curl）；要做必须在 `yes` 之外再单独确认，见下表。每种写法也都先做不带凭据的几项，它们已经显示锁无效时，脚本提示“不建议再打开已登录的程序”并默认跳过手动项。
>
> | 出口 | 要输入什么，才会请你打开已登录的 Claude | 不输入时结果里记 |
> |---|---|---|
> | 到不了 | 不用额外确认（`yes` 即可） | — |
> | 能到，经本机的代理或 TUN | **每个场景**单独输入 `exit-trusted`，表示“我确认此刻的出口是我信任的”。**脚本分不出这条隧道的出口在哪里；如果它的出口仍在国内（例如公司的 VPN），就等同直连。** 切换代理后的新场景重新判断，是经代理的要再确认一次 | `跳过：出口未确认` |
> | 能到，直连 | 单独输入 `real-ip-ok`（整个运行问一次） | `跳过：直连可达` |
> | 锁已经显示无效 | 直连时不能做；经代理时先 `exit-trusted`、再 `open-anyway`；到不了时输入 `open-anyway` | `跳过：锁对系统解析无效…` |
>
> 这几个词（`yes`、`exit-trusted`、`real-ip-ok`、`open-anyway`）互不相同，输错或输别的一律按跳过处理。

## 应急：怎么手动恢复

脚本中途出了意外（终端卡死、机器重启、Claude 一直连不上），按顺序试：

1. 执行还原脚本（可以重复执行，只删内容和脚本写入时一致的文件）：

   ```sh
   sudo scripts/m6/resolver/restore.sh
   ```

2. 还原脚本也用不了时，手动删除下面这几个文件（只删内容是 `nameserver 198.18.0.2` 或 `nameserver 127.0.0.1` 开头、`timeout 1` 结尾的；内容不是这样的是别的软件写的，不要删）：

   ```sh
   cat /etc/resolver/claude.ai /etc/resolver/claude.com /etc/resolver/anthropic.com /etc/resolver/lock-test.claude-abroad.invalid
   sudo rm -f /etc/resolver/claude.ai /etc/resolver/claude.com /etc/resolver/anthropic.com /etc/resolver/lock-test.claude-abroad.invalid
   ```

   `/etc/resolver` 目录原来没有、现在空了的话，也可以 `sudo rmdir /etc/resolver`。脚本的记录在 `/Library/Application Support/claude-abroad-m6r`，手动删完锁文件后可以 `sudo rm -rf "/Library/Application Support/claude-abroad-m6r"`。

删掉之后系统会自动重新读取，不需要重启，也不需要清 DNS 缓存（个别程序可能还缓存着“解析失败”的结果，重开一下那个程序即可）。

## 这是什么

设计 10.2 第一层：在 `/etc/resolver/<域名>` 为 `claude.ai`、`claude.com`、`anthropic.com` 写锁文件，让这些域名只能由 Claude 出国的 DNS 解析；回国后那个地址不可达，解析失败，Claude 连不上。这组脚本在**回国状态**（本项目没有接管网络）下实测：

- 系统解析器、`curl` 的结果（脚本自动记录）；
- Claude Code、Claude 桌面版、浏览器（默认设置、开了加密 DNS）能不能连上（**你自己操作**，脚本提示后你输入 y/n/s）；
- 本机开着别的代理软件（TUN 或系统代理）时的变化（R18；**你自己切换**代理软件，脚本只记录，不替你开关）。

两种写法各跑一遍：`default`（`nameserver 198.18.0.2`）和 `loopback`（`nameserver 127.0.0.1` 加端口）。锁文件的内容和域名清单都来自 Go 包 `internal/resolverlock`（脚本编出 `abroad-dev` 后用 `abroad-dev resolver-lock domains|content` 取得），和以后 abroadd 写的内容同一来源。

## 运行前须知

- **要 sudo**：写 `/etc/resolver` 需要管理员权限。
- **不改网络，不会断网**：脚本只写入、删除自己的锁文件（`/etc/resolver` 原来没有时会建这个目录，结束时空了就删），其余都是只读查询。不碰网卡、路由、DNS 设置、pf，不开关你的代理软件，不启动、不结束任何程序（包括 Claude）。
- **但锁真实域名期间 Claude 可能连不上**：桌面版、Claude Code，**可能包括正在运行的 Claude Code 会话**，直到脚本删掉锁文件。脚本在这一步之前会醒目提示，要你输入 `yes` 才继续。建议在不依赖 Claude Code 会话的时候做，或者在另一台 Mac 上做。
- **反过来，锁无效时已登录的 Claude 会真的连上去**（见最前面）。确认提示里会写明此刻它会从哪里出去（到不了 / 经代理 / 直连）；直连时醒目写出“已登录的账号会从本机 IP 访问”。最稳妥的做法是在**直连到不了 Anthropic** 的网络环境里做；不确定时就让已登录程序的几项跳过，只交不带凭据的结果。
- 默认先做“只锁测试域名”的预演（`lock-test.claude-abroad.invalid`，不影响 Claude），然后才问要不要锁真实域名。
- **四重保护**，都只删自己写的文件（内容和写入时一致的）：正常结束；出错；中断（Ctrl+C、关掉终端）；死人开关（每一轮写入前启动，默认 15 分钟后自动删掉这一轮的锁文件，关掉终端也有效）。
- `/etc/resolver` 下已经有同名文件（别的软件写的，或上一次没清理的）时，脚本一开始就停下来报告，不覆盖。

## 步骤

1. （可选）先空跑看一遍会执行哪些命令，不需要 sudo、不写任何文件：

   ```sh
   scripts/m6/resolver/run.sh --dry-run
   ```

2. 正式运行（会先编出 `abroad-dev`，以你自己的账号编，不用 root）：

   ```sh
   sudo scripts/m6/resolver/run.sh
   ```

   sudo 下找不到 `go` 时：`sudo M6R_GO="$(command -v go)" scripts/m6/resolver/run.sh`。只做预演：加 `--test-domain-only`。

3. 按提示做：
   - 基线（还没写锁）：脚本自动判断出口（到不了 / 经代理或 TUN / 直连），不需要你操作。
   - 预演：脚本自动完成。
   - 输入 `yes` 后锁真实域名。出口是直连时，脚本还会再问一次：输入 `real-ip-ok` 才做已登录程序的观察；出口经代理或 TUN 时，每个场景问一次：输入 `exit-trusted` 才做（只有你确认那条隧道的出口不在国内时才这样输入）。其他输入都跳过。
   - 已登录程序的观察（没跳过时）：先在无锁的状态下试一次作对照，然后每种写法各一次。按提示试 Claude Code、桌面版、浏览器，输入 y（能连上）/ n（连不上）/ s（跳过），后面可以空一格写备注（比如用的哪个浏览器；不要写个人信息）。建议浏览器用无痕窗口（避开已有连接和缓存）；“加密 DNS”一项需要你在浏览器设置里打开安全 DNS，不方便就输入 s。
   - 每种写法都先自动做不带凭据的几项；它们显示锁无效时，脚本提示不建议再打开已登录的程序，默认跳过手动项。
   - 每种写法试完后，脚本问要不要在别的代理状态下再观察一轮：你自己去打开（或关闭）Clash 等软件的 TUN、系统代理，切好后输入一个场景名（如 `tun`、`sysproxy`）回车；想过一会儿再看一次（排除缓存）就输入 `again`；直接回车结束这一种写法。**做完请自己把代理软件恢复成平常的状态。**
4. 结束后把下面两个文件贴回（文件名里有时间戳）：
   - `scripts/m6/resolver/out/evidence-*.txt`（证据）
   - `scripts/m6/resolver/out/run-*.log`（日志）

   证据里不记录出口 IP、局域网地址、用户名、主目录路径（都已脱敏），`curl` 只记录状态码和退出码，不记录响应体，系统代理只记录哪几项开着、不记录地址端口。`out/` 已由本目录的 `.gitignore` 忽略（仓库根目录 `.gitignore` 的 `/scripts/*/out/` 只管一层，管不到 `scripts/m6/resolver/out/`），不会被提交；文件由 root 写入，读不了时用 `sudo cat`。

## 结果文件（evidence-*.txt）里看什么

| 行 | 含义 |
|---|---|
| `基线出口：到不了…` / `能到，经本机的代理或 TUN` / `能到，而且是直连…`，后面跟“依据” | 无锁时不经任何代理能不能到 Anthropic（依据：curl 拿到应答几个、默认路由是否在隧道接口上或系统解析给出 198.18 段的假地址、系统代理、代理环境变量） |
| `环境：…` | 系统代理开着哪几项（不记地址端口）、默认路由的接口、198.18 段的路由、代理环境变量的名字 |
| `解析器 <域名>：已加载` / `系统里没有` | 系统有没有读到锁文件 |
| `原始 scutil --proxy：HTTPEnable=1 …` | 各代理项开没开（不存地址和端口） |
| `原始 netstat -rn：default→en0(UGScg) 0/1→utun9(…) …` | 默认路由、半默认路由、198.18/15 内路由各在哪个接口（不存网关） |
| `原始 scutil --dns：resolver#1 search=有 ns=其他 reach=…;resolver#2 domain=claude.ai ns=198.18/15 port=… reach=…` | 每个解析器：锁的域名（别的域名记“其他”）、地址类别、端口、可达性 |
| `原始 dscacheutil <名字>：地址 N 个（类别）` / `没有地址` | 系统解析器解析出几个地址，各属哪一类（198.18/15、回环、其他） |
| `原始 dig @锁地址（写法） <名字>：有应答 N 条（类别），状态 …` / `无应答…` | 有没有别的程序替锁地址应答（R18 的 TUN 劫持） |
| `原始 curl <URL>：状态码 …，退出码 …，对端地址类别 …` | 不带凭据的访问（退出码 6 = 解析不了；对端是 198.18/15 说明走了 TUN 的假地址） |

“原始”几行只保留判断要用的字段，不存任何具体地址；真机上判断错了，贴回这些行就能据此改解析代码。
| `判断 写法=… 场景=…：锁对系统解析有效/无效（…）；此刻出口：…` | 每种写法、每个场景的判断 |
| `手动 写法=… 场景=… <项目>=y/n/s 备注：…` | 你输入的观察 |
| `手动 … <项目>=跳过：直连可达` / `跳过：出口未确认` / `跳过：锁对系统解析无效…` | 默认跳过的项，**不算不通过** |
| `用户确认锁真实域名：yes`、`用户单独确认直连时也做已登录程序的观察：real-ip-ok`、`用户确认此刻的出口是信任的（写法=… 场景=…）：exit-trusted` | 你做过的确认 |

## 环境变量

| 变量 | 作用 |
|---|---|
| `M6R_DEADMAN_SECS` | 每一轮的死人开关秒数（默认 900，范围 1–3600） |
| `M6R_PORT` | `loopback` 写法的端口（默认用 `abroad-dev` 的默认值 15353；不用 5353，那是 mDNS 的端口） |
| `M6R_GO` | `go` 的路径 |
| `M6R_TEST_DIR` 等 `M6R_TEST_*`（含模拟基线出口的 `M6R_TEST_BASELINE`、模拟锁无效的 `M6R_TEST_LOCK_LEAK`）、`M6R_ABROAD_DEV` | 只给不用 root 的自测用；以 root 运行时按前缀一律拒绝，没有 `M6R_TEST_DIR` 时也拒绝，不能用来把锁写到别处或伪造判断 |

## 文件

| 文件 | 做什么 |
|---|---|
| `run.sh` | 主脚本（前提检查 → 基线和出口判断 → 预演 → 确认 → 两种写法各一轮，先不带凭据、再已登录程序 → 还原） |
| `restore.sh` | 还原：按记录删自己写的锁文件；不依赖 run.sh 和 Go，可重复执行 |
| `lib.sh` | 公共部分（模式和护栏、写入删除、死人开关、脱敏）；通用函数来自 `scripts/lib/common.sh` |
| `commands.txt`、`check-commands.sh` | 命令清单，和空跑输出、源码的核对 |
| `selftest.sh` | 自测（不用 root，用临时目录代替 `/etc/resolver`；覆盖正常、出错、中断、死人开关、同名文件和被改过的文件等反例；基线出口三种结果、直连和经代理时的单独确认、锁无效时跳过手动项、原始输出存档不留地址） |

开发时的检查：`scripts/m6/resolver/selftest.sh`（里面也跑空跑和 `check-commands.sh`）。
