## Anthropic にはもううんざり

私たちはただ、Claude で落ち着いてコードを書き、話し、仕事をしたいだけです。

ところが現実は：踏み台に VPS を借り、指紋ブラウザを入れ、十数個のチェックサイトでタイムゾーン、言語、DNS、WebRTC、IPv6 を一つずつ確認。Clash のルールは何画面分も書いたのに、どこかのバックグラウンドプロセスがこっそり直結している。プロキシが切れた瞬間、Claude Code が自宅の IP で再接続 —— 翌朝届くのは「アカウントは停止されました」のメール。サブスク代は水の泡。

**もうたくさんだ。**

そこで生まれたのが **Claude Abroad（Claude 出国）**：Mac にインストールするネイティブアプリで、パソコン全体に「海外ネットワークカード」を挿し込みます。

- **必要なのは信頼できるプロキシ 1 つだけ。** サブスクリプションを読み込んでノードを選べば、あとはお任せ。
- **Mac 全体が海外に。** 特定のブラウザやターミナルだけではなく、すべてのアプリ、すべての接続、すべての DNS。タイムゾーンと言語まで出口に合わせます。
- **切れたらネットワークも切断。こっそり直結はしない。** プロキシ停止、サービスのクラッシュ、チェック不合格 —— どの場合も Mac はオフラインのままあなたを待ちます。本当の IP をパケット 1 つ漏らすくらいなら、ネットにつながらないほうがまし。
- **戻りたければワンクリックで帰国。** まず片付けてから復元。ネットワーク、タイムゾーン、言語がすべて元どおりに。

使い慣れた Claude デスクトップ版、ターミナルの `claude`、いつものブラウザをそのまま使えます。何も乗り換える必要はありません。

## なぜ「Mac まるごと」なのか

よくあるのは「Claude を隔離環境に閉じ込める」やり方です。仮想マシンのデスクトップを立ち上げ、その中にブラウザ、Claude、開発ツールを入れる。きれいですが、2 つのシステムを行き来することになります。

Claude Abroad は逆です。**Claude を閉じ込めるのではなく、Mac ごと送り出します。**

| | 隔離環境のやり方 | Claude Abroad |
|---|---|---|
| Claude が動く場所 | 仮想マシンのデスクトップの中 | あなたの Mac 上でネイティブに |
| ツールチェーン | 仮想マシンに入れ直し | 手元にあるものをそのまま |
| 管理するトラフィック | 仮想マシンの中だけ | Mac 全体の TCP、UDP、DNS すべて |
| プロキシが切れたら | 仮想マシンがオフライン | Mac 全体がオフライン。どのアプリからも漏れない |
| WeChat やネットバンキングは | もともと外側 | アプリごとにローカルネットワークへ戻せる（Claude のドメインは例外で、決してローカルを通らない） |

裏で動いているのは約 100 MB、GUI なしの Alpine 仮想マシン。役目は 1 つ —— あなたの海外ネットワークカードになること。存在を意識することはありません。

## できること

**🌏 1 つのメインプロキシで全トラフィックを管理**
Clash/Mihomo のサブスクリプション、ローカル YAML、手動の HTTP/SOCKS5 ノード、チェーンプロキシ（中継 → 住宅出口）に対応。TCP と DNS はすべてここを通ります。ノードが UDP に対応していれば UDP も通し、非対応ならブロック。直結に切り替えることはありません。

**🔀 アプリごとに出口を指定して分流**
OpenVPN、WireGuard、別のサブスクリプションを仮想マシンに入れ、指定したアプリだけに使わせられます。Chrome は米国の WireGuard、ターミナルは日本のノード。VPN ごとに独立したネットワーク名前空間を持ち、互いに干渉しません。1 つも入れなくても問題なし。

**🕐 タイムゾーンと言語が出口に追従**
出口チェックに合格すると、Mac のタイムゾーンと言語が出口の所在地に切り替わり、帰国時には元に戻ります。地域はロックされるので、ノードの IP が揺れてもタイムゾーンが勝手に変わることはありません。

**🧪 出国後の 17 項目チェック**
ローカルのアプリの視点から確認：出口 IP、タイムゾーン、言語、IPv6、DNS、WebRTC（STUN）、システムプロキシ、Claude の通信先と到達性……必須項目が不合格なら通信を通さず、Claude も起動させません。照会サービスが一時的に不調でも、誤ってネットワークを切ることはありません。

**🛡️ サービス停止はネットワーク停止**
最後の砦は pf ファイアウォール。サービスの停止、クラッシュ、無効化、メインプロキシのチェック不合格、いずれの場合も Mac はオフラインのまま。自分で「ワンクリック帰国」を押したときだけローカルネットワークが戻ります。

**🧹 帰国の前に片付け**
「ワンクリック帰国」を押すと、まず Claude デスクトップ版や Claude Code など Claude 関連のプロセスをすべて強制終了し、全部終わったのを確認してからローカルネットワークを戻します —— 自宅の IP で再接続する隙を与えません。帰国中は Claude も起動できないので、起動時の自動起動やうっかり起動も防げます。

**🔐 重要な操作は本人の確認が必要**
帰国、アンインストール、メインプロキシの変更、アプリをローカルネットワークへ戻す操作には Touch ID かログインパスワードが必要です。スクリプトや他のプログラムが代わりに押すことはできません。

**🖨️ LAN はいつもどおり**
プリンター、NAS、ルーターの管理画面はデフォルトで許可。不要ならオフにできます。

**🍎 ネイティブ Mac アプリ**
SwiftUI 製の `Claude 出国.app` がメニューバーに常駐し、状態がひと目でわかります。有効化、無効化、帰国、地域の切り替え、アンインストール、どれもワンクリック。

## ソースからのビルド

Go 1.26 が必要です。

```sh
go build ./...
go vet ./...
go test ./internal/...
GOOS=linux GOARCH=arm64 go build ./...    # 仮想マシン内で動く部分
GOOS=windows GOARCH=amd64 go build ./...  # Windows
```

root が必要なテスト、実ネットワークに触れるテスト、システム状態を変更するテストは `//go:build integration` タグの下にあり、デフォルトでは実行されません。

## 使う前に知っておいてほしいこと

- Claude Abroad が管理するのは**ネットワークと地域の環境**で、魔法ではありません。環境チェックが示すのは現在の設定とサンプリングした証拠であり、**どのプラットフォームからもアカウントが制限されないことは保証できません**。
- 有効化すると Mac の全トラフィックが選んだプロキシを通るため、その速度と安定性が使い心地を直接左右します。
- メインプロキシが UDP 非対応の場合、UDP はブロックされます。ブラウザは自動で TCP に切り替わりますが、ビデオ会議、音声通話、ゲームは使えないことがあります。
