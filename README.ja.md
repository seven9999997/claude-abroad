## これは何か

Claude Abroad は Mac 全体に「海外用ネットワークカード」を取り付けます。すべての通信はポケットサイズの Alpine 仮想マシンを経由し、あなたが選んだ**メインプロキシ**から出ていきます。タイムゾーンと言語は出口に合わせて切り替わります。サービスが止まれば Mac 全体がオフラインになり、直接接続へ黙って戻ることはありません。

- **メインプロキシ**：セットアップ時に選択。Mac のすべての通信は既定でこれを通ります（TCP と DNS、ノードが対応していれば UDP も）。Clash/Mihomo のサブスクリプション、ローカル YAML、手動の HTTP/SOCKS5 ノード、チェーンプロキシ（中継 → 住宅出口）に対応し、専用ページでいつでも変更できます。
- **分岐出口（任意）**：OpenVPN、WireGuard、他のサブスクリプションを仮想マシン内で動かし、指定したアプリだけが使います。例：Chrome は米国の WireGuard、ターミナルは日本のノード。何も入れなければ、すべてメインプロキシを通ります。
- **マシン全体をカバー**：仮想ネットワークインターフェースが TCP・UDP・DNS をすべて引き受け、迂回する直接経路はありません。
- **ポケット VM**：約 100 MB の GUI なし Alpine。プロキシエンジンを内蔵し、VPN ごとに独立したネットワーク名前空間を持ちます。
- **アプリ単位でローカル回線**：指定したアプリはローカル回線を直接使えます。ただし Claude のドメインは例外で、どのアプリからでもローカル回線は使いません。
- **LAN はそのまま**：プリンター、NAS、ルーター管理画面は既定で許可（オフにも可）。
- **地域の同期**：メインプロキシの出口チェックに合格すると、VM と Mac のタイムゾーン・言語を一緒に切り替え、戻すときに元へ復元します。
- **フェイルクローズ**：pf ファイアウォールが最後の砦です。サービスの停止・クラッシュ・無効化、またはメインプロキシのチェック不合格時はオフラインのままで、「帰国」をクリックしたときだけローカル回線が戻ります。
- **ネイティブ Mac アプリ**：Swift（SwiftUI）製の `Claude 出国.app`。メニューバーで状態を確認し、有効化・無効化・ローカル回線の復元・地域切り替えをワンクリックで行えます。
- **切り替え後の環境チェック**：ローカルアプリの視点で 17 項目を確認します（出口 IP、タイムゾーン、言語、IPv6、DNS、WebRTC（STUN）、システムプロキシ、Claude の通信先と到達性など）。必須項目が不合格なら通信を通さず Claude も起動させません。照会サービスの一時的な不調で誤ってネットワークを切ることはありません。
- **Claude も一緒に移動**：地域はあなたが操作したときだけ変わります。確認後に Claude を強制終了し、自動では再起動しません（「Claude を開く」を押します）。帰国後は、完全アンインストールするまで Claude は接続も起動もできません。
- **ワンクリックでアンインストール**：再確認の後、Claude を終了し、ネットワークと地域を元に戻し、制御・バックグラウンドサービス・データをすべて削除します。
- **重要な操作は本人確認**：帰国、アンインストール、メインプロキシの変更、アプリをローカル回線に移す操作には Touch ID かログインパスワードが必要で、スクリプトや他のプログラムが代行することはできません。
- **帰国前に片付け**：「帰国」は再確認の後、Claude Desktop や Claude Code など Claude 関連のプロセスをすべて強制終了し、終了を確認してからローカル回線を戻します。

## 状況

**開発中で、まだ使えるリリースはありません。** 上記は設計目標であり、提供済みの機能ではありません。

- **macOS（14 以降、Apple Silicon）**：仮想マシン、データプレーン、pf ファイアウォール規則、メインプロキシ、出口チェック、分岐出口（WireGuard、OpenVPN、Clash ノード）を実装済みで、単体テストと VM 内のエンドツーエンドテストに合格しています。実機での全体検証、ネイティブアプリの UI、インストールとアンインストールが残っています。
- **Windows（10/11 x64）**：着手済み。すべてのコードが Windows 向けにクロスコンパイルでき、システム層は現時点では通信を通さずエラー終了します。Windows フィルタリング プラットフォーム（WFP）による遮断規則を作成中です。

## ソースからのビルド

Go 1.26 が必要です。

```sh
go build ./...
go vet ./...
go test ./internal/...
GOOS=linux GOARCH=arm64 go build ./...    # VM 内で動く部分
GOOS=windows GOARCH=amd64 go build ./...  # Windows
```

root 権限が必要なもの、実ネットワークに触れるもの、システム状態を変えるテストは `//go:build integration` タグの下にあり、既定では実行されません。
