# 桌面端 UI 设计稿

Claude 出国只做 macOS 桌面应用（SwiftUI），不做网页版。

- `index.html`：桌面端交互原型。用浏览器直接打开，不需要构建，也没有后端。画面模拟一台 Mac：顶部系统菜单栏（右侧帽子图标就是本应用的菜单栏图标，可以点开），中间是应用窗口。底部深色条是原型自带的跳转和模拟开关，不属于产品界面。
  - 主窗口：总览、主代理、分流出口、应用分流、环境检测、地区、引擎与虚拟机
  - 安装引导：允许后台服务 → 配置主代理 → 检查 → 启用
  - 设置窗口（⌘,）：通用、环境检测、回国与 Claude、高级（含卸载）
  - 状态对照：已出国、检查中、检测未通过、已断网、已回国
  - 可以点完整流程：一键回国（两次确认 → 强制结束 Claude → 回国 → 重启提示）、一键卸载、启用后强制重启 Claude 并提示重启 Mac
  - 模拟开关：回国后点 Claude 图标（被拦下的通知）、回国时进程结束不了（中止回国）、浅色 / 深色外观
- `canvas/`：早期**网页版面板**的在线画布源文件（`.dc.html`），已经过时，只作存档。它们依赖画布运行时，不能单独打开。

页面上的数据都是示例：IP 使用文档保留地址段（203.0.113.x、198.51.100.x），引擎版本是占位。

视觉按 macOS 原生习惯：系统字体、半透明侧栏、分组表单、弹出菜单、开关、警告框和系统通知。强调色沿用吉祥物的陶土橙；状态颜色只有一个含义：青色放行，黄色检查中，红色断网，灰色本机网络。
