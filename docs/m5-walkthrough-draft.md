# M5 Mac 应用走查清单（草稿）

会话里不启动应用、不创建窗口（m5-plan v2.5 决定 4）：视图代码只经过编译。下面这些要由用户在 Mac 上实际打开应用看，逐项打勾或记下问题。每个界面任务（M5-7 起）往这里追加。

## 怎么打开（M5-7 阶段，开发模式）

1. 起一个开发模式的假系统 abroadd（不碰本机网络）：
   `go build -o /tmp/abroadd ./cmd/abroadd && /tmp/abroadd --fake-system --state-dir /tmp/abroad-walk/st`
2. 另开一个终端：`cd app && swift build && ABROAD_SOCKET=/tmp/abroad-walk/st/api.sock .build/debug/ClaudeAbroad`
   （`.app` 包的组装和 ad-hoc 签名在后面的任务里写成脚本；现在直接运行可执行文件。）
3. 看完：在第二个终端按 Ctrl+C 退出应用，第一个终端按 Ctrl+C 停 abroadd，删掉 `/tmp/abroad-walk`。

## M5-7：菜单栏和首页

### 菜单栏图标的状态

- [ ] 已回国（刚启动时假系统是 RESTORED）：房子图标
- [ ] 已出国（菜单里点“启用”后）：飞机图标
- [ ] 断网（点“停用”后：停用后保护还在）：Wi-Fi 划线图标
- [ ] 检查中（操作进行中，一闪而过）：循环箭头图标
- [ ] 出错（停掉 abroadd 后）：感叹号三角图标；菜单里显示“后台服务没有运行”，启用、停用、回国都不可点
- [ ] 保护失效（停用或启用状态下断网保护没有生效）：感叹号三角图标，菜单和首页显示“断网保护没有生效，可能有别的软件改了系统的防火墙规则”和后台给的处理办法；假系统里不容易造出来，真机走查时如遇到请记下
- [ ] 重新启动 abroadd 后几十秒内自动恢复（重连间隔最长 30 秒）

### 菜单各项

- [ ] 第一行“Claude 出国：<状态>”
- [ ] 主代理出口一行（假系统没有出口基准：显示“这个模式没有出口基准”）
- [ ] “调用方签名校验未启用”一行
- [ ] 启用、停用、一键回国的可点状态与当前状态相符（已回国：只有启用可点；已出国：停用和回国可点）
- [ ] 一键回国：打开主窗口并弹出确认，列出要结束的 Claude 进程（假系统里为 0 个）；点取消什么都不变，点确认后变成已回国
- [ ] “打开主窗口…”能把窗口带到前面；“退出”退出应用

### 首页（对照原型 ui/design/index.html 的首页）

- [ ] 顶部：状态图标和状态文字

- [ ] 需要本人授权时弹出“这一步请在终端执行”，命令可以选中和拷贝（例如 `sudo abroad up`）
