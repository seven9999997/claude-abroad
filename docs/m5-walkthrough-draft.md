# M5 Mac 应用走查清单（草稿）

会话里不启动应用、不创建窗口（m5-plan v2.5 决定 4）：视图代码只经过编译。下面这些要由用户在 Mac 上实际打开应用看，逐项打勾或记下问题。每个界面任务（M5-7 起）往这里追加。

## 怎么打开（M5-7 阶段，开发模式）

1. 起一个开发模式的假系统 abroadd（不碰本机网络；`--fake-main-proxy` 接上假的出口检查和假虚拟机，能走完引导）：
   `go build -o /tmp/abroadd ./cmd/abroadd && /tmp/abroadd --fake-system --fake-main-proxy --state-dir /tmp/abroad-walk/st`
2. 另开一个终端：`cd app && swift build && ABROAD_SOCKET=/tmp/abroad-walk/st/api.sock .build/debug/ClaudeAbroad`
   （`.app` 包的组装和 ad-hoc 签名在后面的任务里写成脚本；现在直接运行可执行文件。）
3. 看完：在第二个终端按 Ctrl+C 退出应用，第一个终端按 Ctrl+C 停 abroadd，删掉 `/tmp/abroad-walk`。

## M5-7：菜单栏和首页

### 菜单栏图标的状态

- [ ] 已回国（刚启动时假系统是 RESTORED）：房子图标
- [ ] 已出国（菜单里点“启用”后）：飞机图标
- [ ] 断网（点“停用”后：停用后保护还在）：Wi-Fi 划线图标
- [ ] 检查中（操作进行中，一闪而过）：循环箭头图标
- [ ] 出错（停掉 abroadd 后）：感叹号三角图标；菜单里显示“后台服务没有运行”，启用、停用、回国都不可点
- [ ] 保护失效（停用或启用状态下断网保护没有生效）：感叹号三角图标，菜单和首页显示“断网保护没有生效，可能有别的软件改了系统的防火墙规则”和后台给的处理办法；假系统里不容易造出来，真机走查时如遇到请记下
- [ ] 重新启动 abroadd 后几十秒内自动恢复（重连间隔最长 30 秒）

### 菜单各项

- [ ] 第一行“Claude 出国：<状态>”
- [ ] 主代理出口一行（假系统没有出口基准：显示“这个模式没有出口基准”）
- [ ] “调用方签名校验未启用”一行
- [ ] 启用、停用、一键回国的可点状态与当前状态相符（已回国：只有启用可点；已出国：停用和回国可点）
- [ ] 一键回国：打开主窗口并弹出确认，列出要结束的 Claude 进程（假系统里为 0 个）；点取消什么都不变，点确认后变成已回国
- [ ] “打开主窗口…”能把窗口带到前面；“退出”退出应用

### 首页（对照原型 ui/design/index.html 的首页）

## M5-8：安装引导与主代理页面

开发模式下属主就是完全信任的调用方：敏感操作直接成功，看不到终端退路。要看终端退路，可在真实模式（以 root 运行的 abroadd、以普通用户打开应用）走查；或者记下“待真机看”。

### 安装引导（新的状态目录时打开应用即进入）

- [ ] 第 1 步“欢迎”：做什么——看说明，点“下一步”；应该看到——步骤条四步，当前一步加粗
- [ ] 第 2 步“后台服务”：先不启动 abroadd 打开应用——显示手动加载的说明、命令（可选中）和“这是临时做法”；“下一步”不可点；再启动 abroadd——几十秒内自动前进到第 3 步
- [ ] 第 3 步“配置主代理”：内嵌主代理页面；没应用主代理时“完成”不可点；应用成功后点“重新检查”（或应用后自动）——“完成”可点
- [ ] 第 3 步点“完成”被后台拒绝时（例如删掉状态目录里的出口基准后）——停在第 3 步，红框里三段显示后台的原因
- [ ] 第 4 步“完成”：显示完成说明；关掉窗口再打开——直接进首页，不再进入引导

### 主代理页面

- [ ] 来源列表：每行只有名字、种类、节点数、更新时间（没有订阅地址和服务器）；订阅有“更新订阅”，都有“删除”
- [ ] 添加来源——订阅地址：填名字和地址，点“添加”；地址框马上清空；未启用且没勾“经本机网络抓取订阅”时，出现说明（会看到你本机的地址），勾上后要重新填地址再提交（假系统不抓取订阅，会显示失败原因）
- [ ] 添加来源——本地配置文件：“选择文件…”或把文件拖进来，显示文件名；添加后列表多一行
- [ ] 添加来源——手动节点：类型 SOCKS5/HTTP、服务器、端口、用户名、密码（密码不回显）；端口不对时提示、不提交；提交后表单的服务器、端口、用户名、密码都清空
- [ ] 更新订阅：未启用时提示要经本机网络，按钮变成“经本机网络更新”；更新后选中的节点不在了时出现橙色提示
- [ ] 选节点：出口节点下拉；“加一跳中转”菜单，可去掉；“应用主代理”——正在应用的转圈和文字，成功后绿色的“主代理已应用：出口在 US（America/Los_Angeles）”
- [ ] 应用失败：红框三段原样；回退成功时下面有“已经回到原来的主代理”，回退没完成时是橙色的提示
- [ ] 已启用时应用、地区会变：弹出通用的确认框（地区 A → B、要结束的进程），取消不变，确认后成功
- [ ] 第一跳是局域网节点：弹出“确认局域网节点”，写着“节点“名字”在你的局域网里，确认后虚拟机可以连到这个地址。”；确认后再点应用就能成功
- [ ] 检查主代理：显示“主代理可用：出口在 …，规则 …”，没有任何地址
- [ ] 终端退路（真实模式、普通用户）：添加订阅时出现两步说明——第一步临时文件的路径，第二步要执行的命令（不含订阅地址和密码）；点“执行完了”后临时文件被删除；拷贝命令可用

### 与原型（ui/design/index.html）的不同

- 原型的主窗口是侧边栏（总览、主代理、分流出口……），这里先用两个标签页（首页、主代理），侧边栏随后续页面一起做。
- 原型的“添加主代理的节点来源”是弹出的对话框，按钮叫“导入并验证”；这里是页面里的一块表单，按钮叫“添加”。
- 原型的本地文件单个上限 8 MiB、可以直接粘贴 YAML；这里上限 2 MiB（和后台的请求体上限一致），暂不支持粘贴。
- 原型的“通过本机网络下载这份订阅”说明“以 Clash 客户端身份下载”；这里的说明按后台的要求写（未启用时才需要、会暴露本机地址）。
- 局域网节点的确认框、终端退路的两步说明原型里没有（按设计文字做）。
