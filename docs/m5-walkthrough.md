# M5 走查清单与真机步骤

> 状态：定稿（M5-11，m5-plan v2.11）。由 `docs/m5-walkthrough-draft.md` 整理而来。会话里不启动应用、不建窗口，视图只经过编译；这份清单交给用户在 Mac 上实际看。

走查分两级，可以只做第一级：

|---|---|---|
| 在哪台机器 | 这台 Mac | 这台 Mac |

## 准备（两级共用，只做一次）

1. 打包应用：`scripts/dev/app-bundle.sh`（编译、组装 `app/.build/bundle/ClaudeAbroad.app`、临时签名；不安装、不启动）。约 1–3 分钟。
2. 第二级还要：`go build -tags abroaddev -o scripts/dev/out/bin/ ./cmd/abroadd`（开发构建：默认要传 `--dev-skip-claude-kill`）、`go build -o scripts/dev/out/bin/ ./cmd/abroad-vm ./cmd/abroad ./cmd/abroad-dev`（正式构建）；虚拟机镜像 `guest/out` 已经有（M2 起就有；没有时跑一次 `scripts/dev/vm-up.sh --no-panic`）。

## 第一级：假系统走查

执行 `scripts/m5/walk-fake.sh`：它启动假系统模式的 abroadd（带假主代理），再打开应用。应用开着时，在脚本的终端里按：

- `d`：只停假后台（应用不动）；
- `u`：用同一个状态目录、同一个 socket 路径把假后台再起来（应用自动重连；引导进度、主代理、出口基准都还在）；
- `q`：全部停掉并清理（在菜单栏图标里点“退出 Claude 出国”也一样）。

`scripts/m5/walk-fake.sh --app-first` 先打开应用、等你按回车才起假后台（L1-03 用）。

**这个模式下是假的或不提供的**（看到这些不算问题）：
- 环境检测：假系统没有，侧边栏“环境检测”一页显示“这个模式不提供”；
- 主代理的出口：假的出口检查，出口固定是文档用的地址（203.0.113.7，US）；
- 订阅地址：假系统不抓取订阅，添加订阅会显示失败原因（本地配置文件和手动节点可以加）；
- 分流出口：可以添加，但没有真实的检查（结果由假实现给出）；
- 回国时的 Claude 进程清单：假进程表，通常是 0 个；
- 敏感操作：你就是假后台的属主，直接成功，**看不到“这一步请在终端执行”**（终端退路在第二级看）；
- 系统通知：只有从应用包运行才会出现；第一次发通知时系统会询问权限。

每项编号后面括号里是对应的完成标准（见文末对照表）。

## 与原型（`ui/design/index.html`）的不同

2026-11-27 按原型改了样式（主窗口改为侧边栏导航、分组表单、陶土橙强调色、状态色、浅色和深色两套配色）。下面是改完之后仍然不同的地方，都是有意的：

- 侧边栏的分组、顺序和名字和原型一致；原型侧边栏的计数小标（分流出口数、未通过项数）没有做。侧边栏底部的状态只有当前状态和后台服务连没连上，原型里的虚拟机内存、Claude 能否启动两行没有（状态接口里没有对应的数）。
- 总览：原型状态卡片里的说明段落、网络闸门、UDP 几项，以及“环境检测”“地区”“连接去向”“正在联网的应用”几块没有做（总览只用状态和出口信息，不另取别的页面的数据）；“需要重启 Mac”的提示条这一版没有。原型的“一键回国…”在这里叫“一键回国”（文字沿用原来的，点了以后照旧弹确认框）。
- 主代理：原型的“当前主代理”（链路图、出口 IP、出口变化规则）、节点表格和“节点来源”的加减按钮没有做；这里是“来源”“添加来源”“应用主代理”三个分组，出口节点和中转用弹出菜单。原型的“添加主代理的节点来源”是弹出的对话框，按钮叫“导入并验证”；这里是页面里的一个分组，按钮叫“添加”。
- 原型的本地文件单个上限 8 MiB、可以直接粘贴 YAML；这里上限 2 MiB（和后台的请求体上限一致），暂不支持粘贴。
- 原型的“通过本机网络下载这份订阅”说明“以 Clash 客户端身份下载”；这里的说明按后台的要求写（未启用时才需要、会暴露本机地址）。
- 分流出口：原型是表格（位置、出口 IP、延迟、UDP 各一列）和弹出的“添加分流出口”对话框（Clash 订阅、配置文件、分享链接、手动节点四种）；这里每个出口一行（类型、状态徽标、检查结果、连接数），导入是页面里的分组：标签、类型（wireguard / openvpn / clash / sharelink）、选配置文件。
- 应用分流：原型的搜索框、“全部 / 正在联网 / 已单独设置”筛选、“没有单独设置的应用”默认去向和“断网时允许”开关列没有做；去向是每行右边的菜单。这里多了原型没有的“域名与其他规则”几个分组（补齐一、三）和“系统进程”折叠一节（补齐四）。
- 环境检测：原型的说明段落、“在设置里跳过某项…”链接没有；设备体检这里是一段文字结果加“运行设备体检”按钮，原型是字体清单和“在字体册中打开”。这里多了“历史”一组（补齐四）。
- 地区：原型的“跟随主代理 / 手动指定”单选、时区和语言的弹出菜单、“地区变化时”“修改内容”“还在用旧语言的应用”几组没有做；这里是锁定的地区和来源、待还原的项、“手动指定”（输入时区和语言）和“跟随出口”按钮。
- 引擎与虚拟机：原型的本机接管、后台服务两组和引擎的安装、升级、回滚按钮没有做（只读页面）；这里是虚拟机一组（管理状态、版本、内核、运行时间）和引擎一组。
- 状态色：原型的检查通过用绿色；这里统一用青色（放行、通过），这样每种颜色只有一个含义：青色放行、黄色检查中或需要留意、红色断网或不通过或出错、灰色本机网络或未运行或跳过。“出错”在原型里没有，按断网对待用红色。
- 菜单栏的菜单用系统菜单，不另外上色；原型菜单里的“重新检测环境”“设置…”两项没有。第一行带状态图标，比原来多一行地区（设计 11.2 写了菜单里显示地区）。
- 确认框：原型一键回国是两步（说明对话框 + 警告框倒数）；这里是统一的一个确认框（m5-plan v2.9 决定 2），样式照原型的对话框（应用图标、标题、说明、分组框、底部按钮），“确认”3 秒后可点，下面显示确认码剩余时间。
- 设置窗口（⌘,）：页签和分组表单的样式照原型；选中页签的图标是系统强调色（原型是陶土橙，系统的偏好设置页签不跟随应用的强调色）。原型里这一版没有实现的项不做：通用的登录时打开、菜单栏图标、分类通知开关和更新；环境检测的定时频率；回国与 Claude 里可勾选、可增删的进程清单、默认退出浏览器和几项“始终”说明；高级里命令行工具的“安装…”和“卸载…”按钮（卸载这里只给终端命令）。原型的设置窗口有诊断包按钮；这里（补齐五起）同样是按钮，另加“包含域名清单”的选项和说明。这里多了原型没有的允许局域网、第一层域名解析锁、第四道开关、回国拦截、首次准备、Claude 访问过的域名、程序完整性几项。
- 局域网节点的确认框、终端退路的两步说明、确认框的倒数和过期，原型里没有（按设计文字做，样式和其他对话框一致）。
